Register project

A T3 project is a folder the agents may work in. Registering runs t3 project add, so T3 owns the project exactly as it owns the ones created in its own UI; this board only mirrors it.

The label shown in ticket dialogs and the board filter; T3 stores it as the project title. Keep it short and unique.

Existing projects

Removing a project deletes it and all of its threads in T3 (the CLI's project remove --force). Tickets and their reports are kept; their cards then show project missing. This cannot be undone.
