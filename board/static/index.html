What the board means

Every column, number and badge, in one place. The full guide has the workflows and the limitations.

Columns

Backlog
Written down, not queued. Move it to Ready when it should compete for the watcher.
Ready
Queued; the watcher may claim it at any moment.
In progress
A T3 thread is working on it, claimed atomically.
Testing
The thread finished; the host is running the ticket's test command.
Review
A second thread judges the work; only VERDICT: ACCEPT releases it.
Done
Branch pushed and report written.
Blocked
Needs a person: a failed test or thread, a usage limit, a deleted thread. The note says which.

Numbers and badges

p1 … p5
Priority: 1 urgent, 2 high, 3 normal, 4 low, 5 later. The watcher takes the lowest number first.
review …
The independent review: accept · first attempt is the normal success; reject · attempt 1 of 2 shows the retry budget.
project missing
The ticket's project no longer exists in T3. The ticket and its report are kept.
